# BOJ 34726 - DRS

## 파일

- `index.html`: 한국어 문제 페이지 스냅샷
- `problem_en.html`: 영어 보기 문제 페이지 스냅샷
- `problem.json`: 문제 메타데이터와 본문

자료는 2026년 4월 21일(KST)에 수집된 원본을 그대로 보존합니다. HTML 스냅샷의 외부 스타일, 이미지 및 스크립트는 인터넷 연결이나 원본 서버 상태에 따라 표시되지 않을 수 있습니다.

문제와 페이지 콘텐츠의 권리는 원저작자 및 백준 온라인 저지에 있습니다.
